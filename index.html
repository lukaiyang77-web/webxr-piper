Instructions

1. Start your Python WebSocket server on the Linux machine.
2. Replace the WebSocket URL above if needed.
3. Open this page in the Quest browser.
4. Tap “Connect WebSocket”.
5. Tap “Enter VR”.
6. Tap “Set Reference” while holding the controller in your neutral pose.
7. Move the right controller. The page will stream controller pose and button state.

Recommended backend logic:
- Save reference when receive set_reference = true
- Compute T_rel = inv(T_ref) @ T_now
- Remap controller axes to robot axes
- Use buttons for gripper/open close and reset
